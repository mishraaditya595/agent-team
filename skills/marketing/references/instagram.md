# Instagram

Adapted from coreyhaines31/marketingskills `social` (platform guide, hooks, carousel frameworks; MIT).

Instagram is visual first: the post is judged by its first image before anyone reads a word. Draft a **carousel** by default (it gets saved and shared more than a single image); a single image only when there's one thing to show.

## Pick a carousel shape

| The content is… | Shape | Slides |
|---|---|---|
| tips, resources or steps on one theme | **Value stack** — cover states the exact count and payoff; one item per slide | 5–10 |
| a result with a method behind it | **Problem → proof** — the result on slide 1, the real problem, the method, the proof last | 6–10 |
| a feature or workflow you can show | **Demo walkthrough** — the outcome on slide 1, one step per slide, the result last | 5–8 |
| a strong view on a common practice | **Callout** — the view, why it's wrong, what to do instead, a fair caveat | 5–7 |

Rules: slide 1 is the thumbnail and must work alone; one idea per slide, a few words on each; same layout on every inside slide; never pad to a bigger count; the last slide asks for one action (save, follow, link in bio, comment a keyword).

## The caption

- The **first line** shows before "more": make it stand alone — the payoff or the problem, specific.
- Then 2–5 short paragraphs of context: the story, the why, the detail the slides can't hold.
- One call to action, matching the last slide.
- 3–8 relevant hashtags at the end (niche over generic).
- No links in the caption (they aren't clickable): say "link in bio".

## Visual brief

Every slide gets a one-line **Visual brief** a designer or an image tool can work from: what's shown, the layout, the one line of on-image text, and the product's look from `project.md`. Use real screenshots of the product where the slide shows the product; never mock up features that don't exist.

## Output

```
### Carousel: <shape> — <n> slides
1. Text: "<on-slide text>" · Visual brief: <one line>
2. …
### Caption
<first line>
<body>
<call to action>
<#hashtags>
```

Plus one alternative first slide (a different hook), so the owner can pick.
